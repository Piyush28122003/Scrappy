# Scrappy
♻️🚀 Scrappy: Gamified Waste Management System 🌍✨  Built a web app to promote sustainable waste management using gamification 🎮 and AI-powered object detection 🧠📸. Users track stats 📊, join cleanup events 🏆, and donate via Stripe 💳. Developed with React, Node.js, MongoDB, and deployed on AWS ☁️ for scalability.
