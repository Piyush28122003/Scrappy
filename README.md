# ♻️ Scrappy: Gamified Waste Management System 🚀

Scrappy is a **web application** designed to promote **sustainable waste management** through **gamification, AI-powered object detection, and community engagement**. By leveraging **modern technologies** and **social incentives**, Scrappy motivates users, especially **Gen Z**, to take proactive steps in keeping their environment clean.

## 🌟 Key Features

- 🎮 **Gamified Dashboard** – Track waste collection activity, achievements, and leaderboard rankings.
- 🏆 **Event Participation** – Host and join garbage collection events to encourage community-driven sustainability.
- 📸 **AI-Based Object Detection** – Identify and categorize waste for proper disposal.
- 💳 **Secure Donations via Stripe** – Contribute to the cause with seamless payments.
- ⚡ **Scalable Backend API** – Built using **Node.js, Express, and MongoDB** for efficient data management.
- ☁️ **Cloud Deployment** – Hosted on **AWS** for reliability and performance.

## 🛠️ Tech Stack

| Component  | Technology |
|------------|------------|
| Frontend  | React.js, TailwindCSS |
| Backend   | Node.js, Express.js |
| Database  | MongoDB |
| AI Model  | Object Detection (TensorFlow/PyTorch) |
| Payments  | Stripe API |
| Cloud     | AWS (EC2, S3) |

- **Node.js** (v16+)
